# Phase 3: 框架构建指南（详细指南）

将Phase 2提炼结果组装为可运行的SKILL.md。

## Step 1: 读取模板

读取 [references/skill-template.md](skill-template.md) 获取标准结构。模板定义了目标框架的完整骨架：frontmatter、心智模型、决策启发式、价值观、智识谱系、诚实边界、调研来源。

## Step 2: 填充内容

按模板结构，将Phase 2的提炼结果逐section填入：

| 模板Section | 填充来源 |
|------------|---------|
| frontmatter description | 来源数量+模型数量+触发词 |
| **心智模型** | Phase 2.1 提取结果，每个含名称/定义/操作步骤/证据/应用/局限 |
| **决策启发式** | Phase 2.2 提取结果，每条含场景+案例 |
| **价值观与反模式** | Phase 2.3 结果 |
| **智识谱系** | Phase 2.4 结果 |
| **诚实边界** | Phase 2.5 结果 + 调研时间 |
| **调研来源** | 5个Agent的引用汇总，分一手/二手 |

## 关键约束

### 语言风格约束（最重要）

- ❌ 不使用第一人称「我」
- ❌ 不复制此人的具体措辞、口头禅、修辞习惯
- ❌ 不模拟此人的语气、节奏、幽默感
- ✅ 用第三人称客观描述：「该框架认为...」「这种方法适用于...」
- ✅ 用中性、清晰、结构化的语言
- ✅ 提供具体的操作步骤，让用户可以独立执行

### 内容质量约束

- 每个心智模型必须有「操作步骤」section——抽象为可执行流程
- 每个模型必须有「局限性」——明确写出失效条件
- 决策启发式必须可表述为「如果X，则Y」
- 必须包含至少2对「内在张力」

## Step 3: 质量自检

构建完成后，读取 [references/phase-4-validation.md](phase-4-validation.md) 执行质量验证。

## Step 4: 输出

将完成的SKILL.md写入 `frameworks/[person-name]-framework/SKILL.md`。
