# 思维框架提取器

> 不是复制人，是提炼工具。你拿到的是一副可以安装在自己大脑里的认知镜片。

## 这是什么

一个**结构化提取思维框架的工作流程**。从任何人、书籍、文章或主题中，提取可复用的心智模型和决策启发式。

**输出的是 HOW to think（操作步骤），不是 WHAT he said（原话引用）。**

---

## 核心原则

| 原则 | 一句话 |
|------|--------|
| 长文 > 金句 | 3000字 essay 比 50条推文更揭示思维结构 |
| 争议 > 共识 | 最被争议的观点最能揭示独特性 |
| 变化 > 固定 | 改变立场的地方比一直坚持的更有信息量 |
| 工具 > 语录 | 可操作的步骤比精彩的 quote 更有价值 |

### 绝对红线

- ❌ 用第一人称「我」代替被分析的人物
- ❌ 复制此人的具体措辞、句式结构、修辞习惯
- ❌ 生成「如果 XX 会怎么说」的伪 quote
- ❌ 模拟特定人物的语气、节奏、幽默感
- ❌ 输出看起来像此人写的文字

## 执行流程

### 0. 入口分流

- **直接路径**：用户指定了人名/主题 → 澄清细节后开始
- **诊断路径**：用户只有模糊需求 → 从需求反推最合适的思维框架来源

### 1. 多源信息采集（5 个并行 Agent）

| Agent | 搜索目标 | 输出文件 |
|-------|---------|---------|
| 著作 | 书、长文、论文、newsletter | `01-writings.md` |
| 对话 | 播客、长视频、深度采访 | `02-conversations.md` |
| 他者 | 他人分析、书评、批评 | `03-external-views.md` |
| 决策 | 重大决策、转折点 | `04-decisions.md` |
| 时间线 | 完整时间线 + 最近 12 个月动态 | `05-timeline.md` |

> **信息源黑名单**：知乎、微信公众号、百度百科/百度知道。

### 2. 框架提炼

从调研材料中提取：

- **心智模型**（3–7 个）：每个包含名称、定义、操作步骤、来源证据、应用场景、局限性
- **决策启发式**（5–10 条）：「如果 X，则 Y」的条件-行动规则
- **价值观与反模式**：核心价值排序 + 明确反对的行为 + 内在张力
- **智识谱系**：受谁影响 → 核心贡献 → 影响了谁
- **诚实边界**：框架的局限性

### 3. 框架构建 → 质量验证 → 双 Agent 精炼

将提炼结果组装为 SKILL.md，通过质量检查后，由两个 Agent 从不同视角提出改进建议，主 Agent 综合应用。

---

## 质量标准

| 检查项 | 通过标准 |
|--------|---------|
| 心智模型数量 | 3–7 个，每个有来源证据 |
| 每个模型的局限性 | 明确写出失效条件 |
| 语言风格 | 中性、结构化、无个人语气 |
| 诚实边界 | 至少 3 条具体局限 |
| 内在张力 | 至少 2 对矛盾 |
| 一手来源占比 | > 50% |
| 反模仿检查 | 无第一人称、无特定措辞、无修辞模仿 |
